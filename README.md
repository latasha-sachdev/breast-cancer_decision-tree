# Breast Cancer Classification using Decision Tree

## Aim

To train the Breast Cancer dataset using a Decision Tree Classifier and find its accuracy.

## Dataset

The dataset is taken from the **UCI Machine Learning Repository**.

It contains breast cancer data classified into:

* **M** - Malignant
* **B** - Benign

## Algorithm

**Decision Tree Classifier**

## Steps

1. Load the dataset.
2. Split the data into training and testing data.
3. Train the Decision Tree model.
4. Predict the test data.
5. Calculate the accuracy.

## Libraries Used

* Python
* Pandas
* Scikit-learn
* ucimlrepo

## Result

The accuracy of the Decision Tree Classifier is displayed in the notebook.

## Conclusion

The Breast Cancer dataset was successfully trained using a Decision Tree Classifier and its accuracy was calculated.
